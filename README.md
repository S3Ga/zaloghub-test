# Todo List (React + TypeScript + Vite)

Приложение для управления списком задач с сохранением состояния в `localStorage`.

## Функционал

- Добавление задач (с валидацией на пустые строки и пробелы).
- Переключение статуса выполнения (выполнено / не выполнено).
- Удаление задач.
- Фильтрация: все, активные, выполненные.
- Сохранение данных в `localStorage` при перезагрузке страницы.
- Визуальное отличие выполненных задач (зачеркнутый текст).

## Структура проекта

- `src/types/todo.ts` — типы TypeScript (`Todo`, `FilterType`).
- `src/hooks/useTodos.ts` — кастомный хук для управления состоянием и `localStorage`.
- `src/components/` — UI-компоненты (`TodoForm`, `TodoFilter`, `TodoItem`).
- `src/App.tsx` — корневой компонент.

## Инструкция по запуску

### 1. Установка зависимостей

При возникновении конфликта версий `typescript` и `typescript-eslint` используйте флаг `--legacy-peer-deps`:

```bash
npm install --legacy-peer-deps
```

### 2. Запуск локального сервера

```bash
npm run dev
```

Проект будет доступен по адресу [http://localhost:5173](http://localhost:5173).

### 3. Сборка проекта

```bash
npm run build
```

## Время выполнения задания
